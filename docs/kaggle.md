# Обучение в Kaggle

Финальные модели обучены в бесплатном Kaggle Notebooks на видеокарте T4: классификатор — около 3,5 минуты, сегментатор — около 14. Локально собираются два архива, в Kaggle их запускает ноутбук `notebooks/kaggle_train.ipynb`, результаты скачиваются одним файлом и вносятся в проект.

Нужны: клон репозитория (архив кода собирается из последнего коммита через git), окружение из `requirements.txt` и подготовленный набор — `data/processed/pool.csv` с кэшем `data/processed/cache/pool_256.*` (архив `brain_mri_cache256.zip` из Releases или `python -m src.import_dataset`, см. README).

## Что уходит в Kaggle

| Архив | Что внутри | Размер |
| --- | --- | --- |
| `kaggle/code_bundle.zip` | `src/`, `configs/`, `requirements-kaggle.txt` из последнего коммита и файл `COMMIT` с его хешем | около 0,1 МБ |
| `kaggle/data_bundle.zip` | `pool.csv` и кэш `pool_256.*` только для обучающей и проверочной частей: 3400 снимков 256×256 с обводками | 144 МБ |

Тестовая часть (582 снимка) в Kaggle не уходит: итоговая оценка делается только локально.

```bash
python -m src.make_kaggle_bundle          # только код
python -m src.make_kaggle_bundle --data   # код и данные
```

Скрипт откажется собирать код, если в `src/`, `configs/` или `requirements-kaggle.txt` есть незакоммиченные правки: архив должен совпадать с коммитом, хеш которого попадет в `reports/experiments.csv`.

## Подготовка в Kaggle

Названия пунктов в интерфейсе Kaggle могут немного отличаться.

1. **Два набора данных.** *Datasets → New Dataset*, видимость **Private**: один с `code_bundle.zip`, другой с `data_bundle.zip`. Имена любые — ноутбук находит файлы по содержимому, распакованные и нет.
2. **Ноутбук.** *Create → New Notebook → File → Import Notebook*, файл `notebooks/kaggle_train.ipynb`.
3. **Настройки ноутбука:** *Input → Add Input* — оба набора; *Settings → Accelerator* — **GPU T4**; *Settings → Internet* — **On** (для установки трех пакетов и загрузки весов ImageNet). Видеокарта и интернет в Kaggle доступны после подтверждения номера телефона.

## Запуск

1. В первой ячейке задать запуски `конфиг:seed` через пробел. По умолчанию — финальные модели:

   ```python
   RUNS = "run1_cls:42 run1_seg_neg:42"
   ```

   Другие варианты из `configs/` и другие seed задаются так же, например `run1_cls:43`. Деление данных от seed обучения не зависит.
2. *Save Version → Save & Run All (Commit)*: вкладку можно закрыть, архив `results_<время>.zip` появится на странице ноутбука в разделе *Output*. В интерактивной сессии файлы из `/kaggle/working` пропадают при ее завершении.
3. Внести результаты в проект:

   ```bash
   python -m src.import_kaggle "<папка загрузок>/results_<время>.zip"
   ```

   Папки запусков ложатся в `models/`, строки — в `reports/experiments.csv`; повторный импорт ничего не дублирует. В папке запуска: `best.pt` (веса выбранной эпохи, конфиг, метрики, хеш коммита), `history.csv`, `val_predictions.csv`, `config.yaml`.
4. Дальше, как в README: `python -m src.presence` (порог), `python -m src.freeze` (финальные веса в `models/final/`), `python -m src.evaluate --split test`.

Ограничения бесплатного Kaggle: около 30 часов видеокарты в неделю и до 12 часов на одну сессию.

## Воспроизводимость

- Один и тот же seed на видеокарте дает одинаковые веса и предсказания — проверено двумя запусками классификатора на seed 42.
- Обучение идет в смешанной точности, а оценка на проверочной части — в обычной, поэтому метрики из Kaggle совпадают с пересчетом на процессоре.
- Проверенное окружение Kaggle: Python 3.13, torch 2.11 (CUDA 12.8), Tesla T4; timm 1.0.30, segmentation-models-pytorch 0.5.0, albumentations 2.0.8 ставятся из `requirements-kaggle.txt`.

## Если что-то пошло не так

| Сообщение | Что сделать |
| --- | --- |
| `код не найден` | подключить набор с `code_bundle.zip` (*Add Input*) |
| `в /kaggle/input нет папки с pool.csv…` | подключить набор с `data_bundle.zip` |
| `видеокарта не найдена` | *Settings → Accelerator → GPU T4* |
| `не удалось загрузить предобученные веса` | *Settings → Internet → On* |
| ошибка на шаге `pip install` | проверить, что интернет включен |
| `ВНИМАНИЕ: <пакет> <версия>, а код проверен на …` | первая ячейка не выполнилась или установка не прошла — перезапустить ее |
| `кэш устарел` | код и данные от разных версий подготовки — пересобрать `data_bundle.zip` и загрузить новую версию набора |
| `запуск … завершился с кодом …` | архив с уже завершенными запусками все равно собран; текст ошибки — в выводе ячейки |

Пробный прогон локально, на процессоре, на маленькой выборке:

```bash
python -m src.kaggle_run --runs run1_cls:42 --input-dir <папка с данными> --work-dir <папка для результатов> \
    --allow-cpu --num-workers 0 --extra "--limit-train 48 --limit-val 32 --batch-size 4"
```
