# Финальная оценка системы

Оценка выполнена один раз, 15 октября 2026 г., на замороженной системе (`models/final/`, коммит `6e4c186`): классификатор `run1_cls` seed 42, сегментатор `run1_seg_neg` seed 42, «опухоль есть», если площадь маски больше 50 пикселей или вероятность опухоли у классификатора не ниже 0,976368. Test: 582 снимка (533 опухоли, 49 «нет опухоли») от 126 групп пациентов; в обучении и выборе модели не использовался. Полные таблицы — `reports/eval_test/metrics.md`, сверка на val — `reports/eval_val/metrics.md`.

## Что изменилось между val и test

- **Наличие опухоли — без потерь.** Чувствительность и specificity на test в пределах интервалов val.
- **Тип опухоли — заметно хуже (96% → 84%).** Ошибки собраны у нескольких пациентов: глиома `p00051` — 19 из 44 срезов названы менингиомой, `p00074` — 9 из 9, `p00021` и `p00036` — по 7–8; менингиома `p00142` — 8 из 13 названы глиомой, `p00672` — 5 из 5. Остальные пациенты почти без ошибок. В val было 7 пациентов с глиомой, и все оказались «легкими». Тип опухоли модель определяет во многом по виду среза, и на новых пациентах это переносится хуже. Оценку типа нужно подавать как «около 84%, зависит от пациента».
- **Уверенность.** На val модель недооценивала себя, на test в середине шкалы переоценивает: при уверенности 0,7–0,9 верно 72,7% ответов (на val — 90,4%). При уверенности от 0,97 верно 98–100% на обеих частях.

## Проверки против shortcut на test

- Стресс-тест (подмена технического профиля файла): ответ «опухоль есть / нет» сменился у 0,6% снимков [0,1; 1,1] — по формату файла классификатор не решает.
- Тест с закрашиванием опухоли: ответ классификатора не сменился ни на одном снимке — как и на val, классификатор отвечает «опухоль» по виду снимка, а не по опухоли. Решение системы поэтому опирается и на сегментатор.
- Попадание максимума Grad-CAM истинного класса в маску (+16 пикселей): 175 из 444 (39,4%).
- Опухоли без маски: сегментатор нашел область у 30 из 30 `figshare_crop` и 58 из 59 `other`.

## Ограничения оценки

- Снимков «нет опухоли» в test 49, из них режим T1 — 20: specificity известна с точностью около ±10 п.п.; здоровых снимков T1 с контрастом в данных практически нет.
- Пациентов с масками в test 27 (глиома — 8): Dice по типам зависит от нескольких пациентов, интервалы широкие.
- Оценка — на 2D-срезах из открытых наборов; данных клиники в проверке нет.
