Идея команды: менингиома прилегает к краю (растет из оболочек), глиома лежит внутри мозга, опухоль гипофиза — в центре у основания черепа. Проверяем по эталонным обводкам Figshare, считая признаки обводки (определения — в `src/check_location.py`, записаны до запуска). Обучение — train, оценка — val; тест не открывался. Модели системы не менялись.

Срезов: train 2229 (155 пациентов), val 391 (25 пациентов; глиома — 7, менингиома — 8, опухоль гипофиза — 10). Интервалы — бутстреп по пациентам; пациентов в val мало, поэтому интервалы широкие.
